# Конфетка для Я.Музыки 🍬

Модуль LSPosed (modern API, libxposed 102) для Яндекс Музыки (`ru.yandex.music`): чистый интерфейс без промо,
настройка плеера, отключение телеметрии, серверные эксперименты Яндекса и внешний вид.
Изучен и проверен на версии **2026.09.5 #167**.

Модуль не открывает функции Плюса, не трогает подписку, DRM и загрузку треков. Статистику прослушиваний (`plays`)
он тоже не блокирует: от неё зависят история, рекомендации и выплаты артистам.

## Возможности

| Раздел | Что делает |
|---|---|
| Чистый интерфейс | Скрывает блоки главной и страниц артистов по группам: промо, предложения подписки, баннеры, квесты, подкасты и книги, концерты, клипы, донаты, визард, div-блоки, волны, релизы, миксы. Свои блоки задаются по имени DTO или типу с сервера, вкладки главной по названию. Журнал пишет в лог все пришедшие типы блоков. |
| Промо | Без всплывающих предложений (триггеры), рекламной заставки, промо-шапки главной, промо в рекомендациях, квестов и виджета Плюса, вкладки «Концерты» и рекламных пушей |
| Плеер | Скрывает похожие треки, блоки об артисте, концерты, описание книг и подкастов, информеры и «слова в волне». Есть полноэкранный текст песни, «спокойная волна» без шейдеров и тряски, скорость анимаций (вплоть до полного отключения) и режим «не гасить экран». |
| Поведение | Отключает телеметрию (AppMetrica, AppsFlyer, Crashlytics, метрики интерфейса), автозапуск музыки при открытии, напоминания об обновлении, просьбы про батарею и обязательный визард. Добавляет настройку «Меньше ИИ» и кнопки Telegram/WhatsApp в «Поделиться». |
| Эксперименты | Любой серверный флаг Яндекса можно переопределить строкой `имя = значение`. Текущие флаги со значениями выгружаются в лог. |
| Внешний вид | Темы, цвета, акцент, шрифты, масштаб, скругления, скрытие View по id/тексту, инспектор экранов |

## Как это устроено

Обфусцированные имена классов в Яндекс Музыке меняются с каждой сборкой, поэтому модуль опирается только на то,
что от версии к версии остаётся стабильным:

- **Блоки экранов.** Каждый блок с сервера проходит через `SkeletonJsonAdapter` и превращается в Gson DTO
  (`PromoBlockDto`, `PayOffersBlockDto`...). Имена DTO приложение сохраняет. Модуль возвращает `null` для
  скрытых блоков, как это уже происходит с неизвестными типами.
- **Промо-запросы.** Retrofit создаёт каждый API через `Proxy.newProxyInstance`, имена интерфейсов
  (`PlayerInformersApi`, `TriggerApi`...) сохранены. Для отключённых API модуль отдаёт `Call`, который сразу
  завершается ошибкой, и приложение просто ничего не показывает на этом месте.
- **Эксперименты.** Все флаги читаются через один резолвер. Его находит встроенный сканер dex (`DexScanner`)
  по строке `"Unknown experiment - "`, а базовый класс эксперимента находится по суффиксу `"_NotReady"`.
  Сканирование выполняется один раз на сборку приложения (около секунды при первом запуске), результат
  кэшируется в `files/yacandy_dex.cache` Музыки.
- **Телеметрия.** Конфиги AppMetrica получают `dataSendingEnabled=false` через публичный API SDK.
  Хосты сторонних трекеров не резолвятся.
- **Пуши, анимации, экран.** Работают через классы Android: `NotificationManager.notify` (каналы рассылок),
  `ValueAnimator`/`Settings.Global` (скорость анимаций, её читает и Compose), флаг окна.
- **Внешний вид.** Тоже через классы Android: `Paint`, `Canvas`, шейдеры, `Typeface`, `Outline`, `densityDpi`.

Внешний вид меняется на лету. Остальные разделы начинают работать после перезапуска Музыки (кнопка внизу экрана настроек).

## Установка

1. Скачайте `YaMusicCandy.apk` из артефактов сборки GitHub Actions (workflow **YaMusicCandy - Build**) и установите его.
2. В LSPosed Manager включите модуль. Область действия, Яндекс Музыка, подставится сама.
3. Остановите Яндекс Музыку принудительно и откройте её снова.
4. Откройте «Конфетку» и выберите тему.

Требования: LSPosed с поддержкой API 101+ и Android 8.1+.

## Сборка

```bash
cd YaMusicCandy
./gradlew assembleRelease
```

Нужен Android SDK с `platforms;android-37`: libxposed 102 собран под compileSdk 37.

Без секретов CI подписывает APK одноразовым debug-ключом, поэтому перед установкой новой сборки старую придётся удалить.
Чтобы обновления ставились поверх, добавьте в Secrets репозитория:
`CANDY_KEYSTORE_B64` (keystore в base64), `CANDY_KEYSTORE_PASSWORD`, `CANDY_KEY_ALIAS`, `CANDY_KEY_PASSWORD`.

## Если что-то не применилось

- Часть цветов осталась прежней. ART мог встроить (inline) вызов в уже скомпилированный код приложения.
  Помогает очистка кэша приложения или переустановка Яндекс Музыки без удаления данных.
- Оттенок перекрасился не там, где нужно. Сузьте диапазон оттенков акцента или задайте точную замену цвета.
- Элемент не скрывается. Скорее всего, экран сделан на Compose: инспектор помечает такие экраны как `[Compose]`.
  Для главной используйте «Журнал блоков» и скрывайте блок по его DTO или типу.
- Эксперимент не сработал. Включите «Записать текущие флаги в лог», найдите в логе LSPosed нужное имя и значение.
  Часть функций Яндекс включает только на сервере, одного флага в приложении для них недостаточно.
- После обновления Музыки модуль первый раз заново сканирует приложение. В логе LSPosed появится строка `dex scan took ... ms`.
