# Конфетка для Я.Музыки 🍬

Модуль LSPosed (modern API, libxposed 102) для кастомизации интерфейса Яндекс Музыки (`ru.yandex.music`).
Он меняет только внешний вид: подписки, защиту и сетевые запросы приложения модуль не трогает.

## Возможности

| Раздел | Что делает |
|---|---|
| Готовые темы | Карамель, Мята, Океан, Лаванда, Закат, AMOLED: применяются в одно касание |
| Цвета | Свой акцент вместо фирменного жёлтого (задаётся диапазон оттенков), сдвиг оттенка, насыщенность, фон тёмной и светлой темы, цвет текста и иконок, точная замена `#FFDB4D = #FF6FB5` |
| Шрифт | Встроенные системные семейства или свой `.ttf`/`.otf`; жирность сохраняется, есть ползунок толщины и размер текста |
| Форма и размер | Масштаб всего интерфейса и сила скругления углов (обложки, карточки, кнопки) с защитой круглых элементов |
| Скрытие элементов | По id ресурса или тексту (только для классических View) плюс инспектор, который пишет дерево экрана в лог LSPosed |

Изменения применяются на лету: открытый экран Яндекс Музыки пересоздаётся.

## Как это устроено

Модуль не завязан на обфусцированные классы приложения, поэтому обновления Яндекс Музыки его не ломают.
Все хуки стоят на классах Android:

- цвета: `Paint.setColor`, `Canvas`/`BaseRecordingCanvas.drawColor`, конструкторы `LinearGradient`/`RadialGradient`/`SweepGradient`,
  `PorterDuffColorFilter`/`BlendModeColorFilter`, цвета системных панелей. Через этот путь проходят и View, и Jetpack Compose;
- шрифт: `Paint.setTypeface`;
- скругления: `Outline.setRoundRect`, `drawRoundRect`, `Path.addRoundRect`;
- масштаб: `Activity.attachBaseContext` с изменёнными `densityDpi`/`fontScale`.

Настройки передаются через remote preferences LSPosed, а свой шрифт через remote files.

## Установка

1. Скачайте `YaMusicCandy.apk` из артефактов сборки GitHub Actions (workflow **YaMusicCandy - Build**) и установите его.
2. В LSPosed Manager включите модуль. Область действия, Яндекс Музыка, подставится сама.
3. Остановите Яндекс Музыку принудительно и откройте её снова.
4. Откройте «Конфетку» и выберите тему.

Требования: LSPosed с поддержкой API 101+ и Android 8.1+.

## Сборка

```bash
cd YaMusicCandy
./gradlew assembleRelease
```

Нужен Android SDK с `platforms;android-37`: libxposed 102 собран под compileSdk 37.

Без секретов CI подписывает APK одноразовым debug-ключом, поэтому перед установкой новой сборки старую придётся удалить.
Чтобы обновления ставились поверх, добавьте в Secrets репозитория:
`CANDY_KEYSTORE_B64` (keystore в base64), `CANDY_KEYSTORE_PASSWORD`, `CANDY_KEY_ALIAS`, `CANDY_KEY_PASSWORD`.

## Если что-то не применилось

- Часть цветов осталась прежней. ART мог встроить (inline) вызов в уже скомпилированный код приложения.
  Помогает очистка кэша приложения или переустановка Яндекс Музыки без удаления данных.
- Оттенок перекрасился не там, где нужно. Сузьте диапазон оттенков акцента или задайте точную замену цвета.
- Элемент не скрывается. Скорее всего, экран сделан на Compose: инспектор помечает такие экраны как `[Compose]`.
