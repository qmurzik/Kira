# KIRA.exe — По ту сторону экрана

Уютная романтическая 2D-приключенческая игра для Windows о Кире — девушке из маленького выдуманного мира, который начинает тихо исчезать. Вместе с ней игрок исследует ночной город, крышу под звёздами, заброшенную библиотеку и поезд между мирами, чтобы узнать, почему забываются истории, и дописать последнюю страницу.

> «Даже маленький вымышленный мир может подарить настоящие эмоции».

Игра полностью на русском языке, работает без интернета, регистрации и внешних сервисов. Все «странности» с экраном происходят только внутри игры: она не трогает файлы, другие программы и систему.

## Запуск

### Готовая сборка (Windows 10/11)
1. Распакуйте `KIRA.exe-windows.zip` в любую папку.
2. Запустите `KIRA.exe`. Установка не требуется.

Сохранения и настройки лежат в `%APPDATA%\Godot\app_userdata\KIRA.exe — По ту сторону экрана\`.

### Из исходников
1. Установите [Godot 4.3](https://godotengine.org/download) (стандартная версия, не .NET).
2. Откройте Godot → «Импорт» → выберите файл `project.godot` из этой папки.
3. Нажмите F5 (или «Запустить проект»).

### Сборка .exe самостоятельно
1. В Godot: «Редактор» → «Управление шаблонами экспорта» → скачать шаблоны для 4.3.
2. «Проект» → «Экспорт…» → пресет **Windows Desktop** уже настроен → «Экспортировать проект».

Или из командной строки:
```
godot --headless --path . --export-release "Windows Desktop" build/windows/KIRA.exe
```
PCK встраивается в exe (`embed_pck`), поэтому на выходе один файл.

## Управление

| Действие | Клавиши |
|---|---|
| Основные действия, объекты, ответы | Мышь (левая кнопка) |
| Скрыть окно диалога | Правая кнопка мыши / V |
| Продолжить диалог | Enter / Пробел |
| Меню паузы | Escape |
| Показать интерактивные объекты | Tab (удерживать) |
| Полноэкранный режим | F11 |
| История диалогов | H / колесо вверх |
| Пропуск прочитанного | Ctrl (удерживать) или кнопка «Пропуск» |
| Авточтение | A |
| Быстрое сохранение / загрузка | F5 / F9 |

Все клавиши можно переназначить: «Настройки» → «Управление».

## Что есть в игре

- **5 глав и 3 концовки**: «Наш маленький мир», «Новый рассвет», «Созвездие воспоминаний». Ни одна не наказывает за редкие визиты — концовку выбираете вы вместе с Кирой, а её предложение зависит от того, какими были ваши отношения.
- **6 локаций**: комната Киры, ночной город под дождём, крыша под звёздами, заброшенная библиотека, поезд между мирами и пространство «по ту сторону экрана».
- **Живая Кира**: 13 эмоций, моргание, дыхание, покачивание волос, движение губ при речи, разные позы рук, 6 нарядов.
- **Отношения без «счётчика любви»**: доверие, взаимопонимание и дух приключений + память о важных решениях — Кира ссылается на них позже, вплоть до финала.
- **Мини-игры**: созвездия (7 созвездий), готовка (3 рецепта из шагов: выбор ингредиентов, размешивание, нагрев, точный момент, налив), сбор воспоминаний (пазл), украшение комнаты (10 предметов декора в 8 местах), кодовый замок архива.
- **Время суток** (утро, день, вечер, ночь) меняется по ходу игры: освещение, небо за окном, музыка, реплики.
- **Кастомизация**: наряды, обои, 4 режима освещения, 4 цветовые темы интерфейса, декор. Всё сохраняется.
- **Свободный режим** после финала: разговоры, занятия, прогулки по всем местам, случайные события и необязательные беседы.
- **Сохранения**: автосохранение, быстрый слот, 6 ручных слотов с миниатюрами; контрольная сумма, атомарная запись и резервная копия защищают от повреждённых файлов.
- **Настройки**: громкость (общая, музыка, эффекты, атмосфера, голос), режим окна (оконный, безрамочный, полноэкранный), размер окна, VSync, количество частиц, тряска, интенсивность эффектов «сбоя», скорость текста и авто-режима.

Совет: если ищете, на что нажать, удерживайте **Tab** — все интерактивные объекты подсветятся. А ещё попробуйте понажимать на заколку Киры…

## Структура проекта

```
project.godot, export_presets.cfg   — настройки проекта и экспорта
scenes/        main_menu.tscn, game.tscn
scripts/
  autoload/    GameManager, SceneManager, DialogueManager, RelationshipManager,
               SaveManager, AudioManager, InventoryManager, TimeManager,
               MinigameManager, Settings, UIKit (стиль интерфейса)
  game/        game_world.gd (игровой мир), story_director.gd (ход сюжета)
  characters/  kira.gd — персонаж из векторных слоёв
  locations/   базовая локация + комната, город, крыша, библиотека, поезд, «экран»
  minigames/   звёзды, готовка, пазл, декор, замок
  ui/          диалоговое окно, HUD, меню, настройки, сохранения, дневник, гардероб…
  fx/          дождь, звёзды, пылинки, свечение
data/
  story.json          — главы и шаги сюжета (цели, условия, сценарии)
  dialogue/*.json     — все диалоги (редактируемые)
  locations/*.json    — интерактивные объекты локаций
  items.json, constellations.json, recipes.json, talk.json, idle.json
assets/        kira (слои персонажа), bg (фоны), decor, memories, ui, audio, fonts
shaders/       эффект «сбоя», мягкое свечение
tools/         генераторы ассетов (Python) и скрипты проверки
tests/         автотесты
```

Зависимости модулей однонаправленные: менеджеры состояния не знают о сохранениях; `SaveManager` собирает их состояние сам; мир (`game_world.gd`) исполняет сюжетные команды, а `DialogueManager` общается с ним через интерфейс обработчика.

### Формат диалогов

Сценарий — массив команд в `data/dialogue/*.json`:
```json
"room_window": [
  {"kira": "Смотри, звёзды!", "e": "happy"},
  {"choice": [
    {"t": "«Красиво»", "rel": {"trust": 1}, "do": [{"kira": "Правда?", "e": "shy"}]},
    {"t": "«Это просто газ»", "rel": {"understanding": 1}}
  ]},
  {"if": "flag('drew_cat')", "kira": "Там наша кошка!"}
]
```
Основные команды: `kira`, `n` (рассказчик), `sys`, `say`+`who`, `choice`, `if/then/else`, `label/go`, `call`, `random`, `set`, `inc`, `rel`, `remember`, `unlock`, `give`, `music`, `sfx`, `loc`, `time`, `fx`, `event`, `minigame`, `outfit`, `ending`. Условия — выражения Godot с функциями `flag()`, `count()`, `mem()`, `remembered()`, `placed()` и переменными `chapter`, `trust`, `understanding`, `spirit`, `time`, `free`, `loc`, `ending`.

Сценарии объектов подбираются по имени: `<локация>_<объект>_first` (первый раз), `_ch<N>` (в главе), `_<время суток>`, `_free` (свободный режим), затем общий.

## Ассеты и лицензии

Вся графика, музыка и звуки созданы специально для этой игры и генерируются скриптами из `tools/`:
- `gen_kira.py` — слои персонажа (SVG), `gen_bg.py` — фоны, `gen_items.py` — иконки, декор, иллюстрации воспоминаний;
- `gen_audio.py` — музыка (10 композиций), атмосферные звуки и эффекты (синтез на numpy, кодирование ffmpeg).

Шрифты Nunito, Comfortaa, Marck Script, JetBrains Mono распространяются по лицензии SIL Open Font License 1.1 (тексты лицензий в `assets/fonts/`). Движок Godot — лицензия MIT.

## Проверка качества

```
tools/check_scripts.sh   # синтаксис всех GDScript-файлов
tools/run_tests.sh       # автотесты (≈ несколько минут)
```
Автотесты проверяют: корректность всех сценариев (ссылки, метки, эмоции, условия, ID предметов), наличие ассетов, все мини-игры, сохранение/загрузку, восстановление из резервной копии и отказ на повреждённых файлах, а также **полное прохождение сюжета до каждой из трёх концовок** с последующей проверкой свободного режима.
