# TwinFTP 1.0.0

Первый выпуск двухпанельного FTP-менеджера для iPhone.

**Файл `TwinFTP-unsigned.ipa` не подписан.** Перед установкой подпишите его своим сертификатом
в IPA-сайнере (Sideloadly, AltStore/SideStore, ESign и т. п.). Без подписи iOS его не установит.

## Возможности
- Две независимые панели (iPhone и FTP), смена сторон, разворот панели, перетаскиваемый разделитель.
- Свой FTP-клиент: PASV/EPSV, MLSD с откатом на LIST, UTF-8 и Windows-1251, SIZE/MDTM/REST, переподключение.
- Очередь передач: рекурсивные папки, параллельные соединения, пауза, докачка, повтор, конфликты имён.
- Безопасная загрузка через временный файл с проверкой размера; права заменяемого файла сохраняются.
- ZIP: просмотр, распаковка (ZipCrypto/AES), упаковка, «Распаковать и загрузить на FTP», «Скачать и распаковать».
- Редактор кода: вкладки, подсветка PHP/HTML/CSS/JS/JSON/XML/.htaccess, поиск и замена, сохранение прямо на сервер.
- Просмотр файлов через QuickLook, импорт из «Файлов» и через «Поделиться», избранные папки.
- Профили серверов, пароли в Keychain, диагностика подключения, журнал команд без паролей.

## Ограничения
- В фоне передача продолжается ~30 секунд (ограничение iOS), затем очередь ставится на паузу и продолжается при возврате.
- Только обычный FTP: FTPS/SFTP и активный режим не поддерживаются. RAR/7z не поддерживаются.

Подробности — в `TwinFTP/README.md`.
