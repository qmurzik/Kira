# TwinFTP

Двухпанельный файловый менеджер для iPhone с подключением к обычному FTP-серверу.
Слева — файлы iPhone, справа — FTP-сервер (стороны можно поменять). Массовая загрузка
и скачивание с рекурсией по папкам, очередь с паузой и докачкой, ZIP-архивы,
встроенный редактор кода с подсветкой синтаксиса для быстрой правки сайтов.

* Платформа: iOS 17.0+ (проверочная цель — iPhone XS на iOS 18.7), Swift 5, SwiftUI + UIKit.
* Интерфейс на русском языке, тёмная (графит и фиолетовый) и светлая темы.
* Без серверной инфраструктуры, рекламы, аналитики и аккаунтов. Пароли — только в связке ключей iOS.
* Сторонних зависимостей нет: FTP-клиент, ZIP и подсветка синтаксиса написаны с нуля.
  Используются системные библиотеки: Network.framework, zlib, CommonCrypto, QuickLook.

## Структура

```
TwinFTP/
├── TwinFTP.xcodeproj           — проект Xcode (генерируется Scripts/generate_xcodeproj.py)
├── App/TwinFTP/                — приложение (SwiftUI/UIKit)
│   ├── App/                    — точка входа, AppModel
│   ├── Main/, Panels/          — двухпанельный экран, панели, диалоги
│   ├── Servers/                — список серверов, редактор профиля, диагностика подключения
│   ├── Transfers/              — очередь передач, конфликты имён
│   ├── Editor/                 — редактор кода (TextKit 1, номера строк, подсветка)
│   ├── Archive/, Viewer/       — архивы ZIP, просмотр QuickLook, системные пикеры
│   ├── Settings/               — настройки, журнал FTP
│   └── Resources/              — Info.plist, иконка, цвета
├── App/TwinFTPUITests/         — UI-тест на симуляторе с реальным FTP-сервером (снимки экрана)
├── Packages/TwinCore/          — ядро (Swift Package, собирается и тестируется и на Linux)
│   ├── FTP/                    — FTP-клиент поверх сокетов (Network.framework и BSD)
│   ├── Transfer/               — движок очереди передач
│   ├── Archive/                — чтение/запись ZIP (Deflate, ZIP64, ZipCrypto, AES)
│   ├── Editor/                 — кодировки, переводы строк, подсветка синтаксиса
│   └── Files/                  — модели, пути, локальная файловая система
└── Scripts/                    — тестовый FTP-сервер, генераторы проекта, иконки, фикстур
```

## Сборка

### GitHub Actions (рекомендуется)

Workflow `.github/workflows/twinftp-ios.yml` запускается при push в файлы `TwinFTP/**`
и вручную (Actions → «TwinFTP iOS» → Run workflow). Он:

1. запускает тесты ядра `swift test` (юнит-тесты и интеграционные тесты с настоящим FTP-сервером pyftpdlib);
2. собирает приложение `xcodebuild -sdk iphoneos` без подписи;
3. упаковывает **unsigned IPA** со структурой `Payload/TwinFTP.app` и проверяет её;
4. запускает UI-тест на симуляторе против локального FTP-сервера и сохраняет снимки экрана;
5. при ручном запуске с флагом «Опубликовать GitHub Release» создаёт релиз с IPA и исходниками.

Артефакты: `TwinFTP-unsigned-ipa` (IPA + SHA256) и `TwinFTP-logs-and-screenshots`.

### Локально (macOS + Xcode 16 или новее)

```bash
cd TwinFTP
python3 Scripts/generate_xcodeproj.py      # только если добавляли/удаляли файлы
open TwinFTP.xcodeproj                      # выберите свою команду в Signing & Capabilities
# или из терминала:
xcodebuild -project TwinFTP.xcodeproj -scheme TwinFTP -sdk iphoneos -configuration Release \
  CODE_SIGNING_ALLOWED=NO build
```

Тесты ядра (macOS или Linux со Swift 5.9+):

```bash
python3 -m pip install pyftpdlib pyzipper   # для интеграционных тестов
cd TwinFTP/Packages/TwinCore && swift test
```

Без pyftpdlib интеграционные тесты помечаются как пропущенные (XCTSkip), а не как пройденные.

## Установка на iPhone

Unsigned IPA **сам по себе не установится** — iOS требует действующую подпись.

1. Скачайте `TwinFTP-unsigned.ipa` из артефактов Actions или из GitHub Release.
2. Подпишите своим сертификатом в любом IPA-сайнере (например, Sideloadly, AltStore/SideStore,
   ESign/GBox/Scarlet с вашим .p12 + .mobileprovision, или `codesign` в Xcode).
   Bundle ID по умолчанию — `com.twinftp.app`; сайнер может заменить его на разрешённый вашим профилем.
3. Установите подписанный IPA. При бесплатном Apple ID подпись действует 7 дней.

Расширений (app extensions) и особых entitlements у приложения нет — подходит любой профиль разработки.

## Подключение к FTP

1. На главном экране в правой панели нажмите «Новый сервер» (или значок сервера вверху слева).
2. Укажите адрес (`ftp.example.com`, без `ftp://`), порт 21, логин и пароль от хостинга.
   Начальная папка — например, `/public_html` или `/www/site.ru` (можно оставить пустой).
3. Нажмите «Проверить подключение» — будет показан пошаговый отчёт и журнал команд (пароль скрыт).
4. Сохраните и нажмите на сервер. Перед первым подключением приложение предупредит, что FTP не шифрует трафик.

Если вход проходит, а список файлов не загружается — в «Дополнительно» попробуйте режим «Только PASV»
или переключите «Исправлять адрес PASV за NAT». Для старых серверов с русскими именами в Windows-1251
выберите соответствующую кодировку (по умолчанию она определяется автоматически).

## Как пользоваться

* **Активная панель** подсвечена акцентной рамкой; нижняя панель действует на неё.
  Стрелка на кнопке «Загрузить/Скачать» показывает направление передачи.
* **Выбор**: кнопка ✓ внизу или «Выбрать» в контекстном меню; затем касания отмечают файлы.
* **Контекстное меню** — долгое нажатие на файл. Свайп вправо — копировать в соседнюю панель,
  свайп влево — удалить/переименовать. Перетаскивание строки в другую панель тоже запускает копирование.
* **Путь**: «‹» — назад по истории, «↰» — вверх; хлебные крошки кликабельны, долгое нажатие —
  ввод пути вручную. Избранные папки — в меню «…» панели.
* **Разделитель** между панелями можно тянуть; двойное касание — 50/50. «Развернуть панель» — в меню «…».
* **Импорт**: «…» → «Импорт из «Файлов»»; из Telegram/Safari — «Поделиться» → «TwinFTP»
  (файл попадёт в папку «Входящие»). Папку TwinFTP видно в «Файлах» → «На iPhone».
* **Редактор**: PHP, HTML, CSS, JS, JSON, XML, .htaccess, конфиги. Вкладки, поиск и замена,
  переход к строке, отмена/повтор, панель символов над клавиатурой, автоотступы.
  Удалённый файл сохраняется на сервер через временный файл; перед сохранением проверяется,
  не изменился ли файл на сервере.

## Ограничения (честно)

* **Фоновая работа.** iOS не даёт приложениям неограниченно передавать данные по FTP в фоне.
  После сворачивания у TwinFTP есть ~30 секунд, затем очередь ставится на паузу, сохраняется и
  автоматически продолжается при возврате (с докачкой, если сервер поддерживает REST).
* **Только обычный FTP.** FTPS (TLS) и SFTP в этой версии не реализованы. Активный режим (PORT)
  не поддерживается — на iPhone он почти никогда не работает из-за NAT; используется PASV/EPSV.
* **Копирование между двумя FTP-серверами** напрямую невозможно (FXP не реализован): скачайте на iPhone и загрузите.
* **Архивы:** поддерживается только ZIP (Store/Deflate, ZIP64, ZipCrypto, AES-128/192/256 WinZip).
  RAR и 7z не поддерживаются. Новые архивы создаются без пароля. Символьные ссылки из архивов не создаются.
* **Права доступа** меняются командой `SITE CHMOD` — не все серверы её поддерживают.
* **Корень файловой системы iOS недоступен**: приложение работает в своей папке и в папках,
  к которым вы дали доступ через «Файлы».
* **Перетаскивание (drag & drop)** реализовано стандартными средствами SwiftUI; на iPhone оно
  работает начиная с iOS 15, но было проверено только в симуляторе/коде, не на физическом устройстве.

## Тесты

* `Packages/TwinCore/Tests` — 51 тест: разбор ответов FTP (многострочные, PASV/EPSV/PWD/MDTM),
  листинги (MLSD, Unix `ls -l` с русскими месяцами, DOS/IIS), пути, локальные операции, кодировки,
  подсветка; интеграционные тесты с реальным pyftpdlib — загрузка/скачивание, кириллица и пробелы,
  Windows-1251, пустые файлы, докачка REST/APPE, отмена посреди передачи, падение сервера,
  массовая рекурсивная передача 100+ файлов, конфликты имён, пауза/возобновление, ZIP
  (ZipCrypto, AES, CP866, Zip Slip, zip-бомбы, проверка `unzip -t`).
* `App/TwinFTPUITests` — сквозной сценарий на симуляторе: подключение к FTP, загрузка папки,
  открытие PHP-файла с сервера в редакторе, очередь, настройки, альбомная ориентация; снимки экрана.

## Лицензия

Исходный код TwinFTP. Сторонние библиотеки не используются; zlib и системные фреймворки
поставляются вместе с iOS.
