# Файлообменник без регистрации

Простой self-hosted файлообменник: загружаете файл(ы) — получаете ссылку.
По ссылке получатель видит удобную страницу: фото и видео открываются
превью прямо в браузере, текстовые файлы можно посмотреть без скачивания,
а всё остальное — скачивается в один клик (или всё сразу архивом ZIP).
Без учётных записей, паролей и БД — только PHP + JSON-файлы метаданных.

## Стек

- **HTML** — `index.html` (страница загрузки)
- **PHP** — `upload.php`, `share.php`, `file.php`, `zip.php`, `cleanup.php`, `lib.php`, `config.php`
- **JS** — `app.js` (загрузка, drag&drop, прогресс), `share.js` (превью, лайтбокс, копирование ссылки)
- **CSS** — `style.css`
- **JSON** — `storage/meta/<id>.json` — метаданные каждой ссылки (список файлов, срок действия)

## Как это работает

1. `index.html` + `app.js`: пользователь перетаскивает файлы или выбирает
   их через диалог, выбирает срок жизни ссылки и жмёт «Загрузить».
   Загрузка идёт через `XMLHttpRequest` с индикатором прогресса.
2. `upload.php` проверяет лимиты, сохраняет файлы в
   `storage/files/<id>/` и пишет метаданные в `storage/meta/<id>.json`,
   возвращает ссылку `share.php?id=<id>`.
3. `share.php` рендерит страницу просмотра: изображения — как превью с
   открытием в полноэкранном лайтбоксе, видео/аудио — через `<video>`/`<audio>`,
   PDF — во встроенном iframe по клику, текстовые файлы — кнопка
   «Просмотр», которая подгружает содержимое через `file.php?mode=raw`
   (вставляется как `textContent`, поэтому HTML/скрипты внутри файла не
   исполняются). Для всего остального — просто кнопка «Скачать».
4. `file.php` отдаёт байты файла (inline для превью или attachment для
   скачивания), `zip.php` — все файлы ссылки одним ZIP-архивом.
5. Ссылка автоматически перестаёт открываться после истечения срока —
   `cleanup.php`, запущенный по cron, физически удаляет истёкшие файлы.

## Установка

1. Скопируйте папку `file-sharing/` на хостинг с PHP 7.4+ (нужны
   расширения `fileinfo` и `zip` — последний используется только для
   кнопки «Скачать всё (ZIP)»).
2. Убедитесь, что веб-сервер может писать в `storage/files/` и
   `storage/meta/` (права `755`/`775` на владельца веб-сервера).
3. При необходимости поднять лимиты загрузки — под PHP-FPM/CGI это уже
   делает `.user.ini` в этой папке; под `mod_php` задайте
   `upload_max_filesize`/`post_max_size` в конфиге виртуального хоста.
4. (Опционально) добавьте в cron очистку истёкших ссылок:
   ```
   0 * * * * php /path/to/file-sharing/cleanup.php
   ```
5. Откройте `index.html` в браузере.

## Настройки

Все лимиты и срок действия ссылок по умолчанию — в `config.php`:
максимальный размер файла и суммарный размер загрузки, максимальное
число файлов в одной ссылке, размер файла, до которого доступен
текстовый предпросмотр, и список доступных сроков действия ссылки.

## Безопасность

- Ссылки на файлы используют непредсказуемый 128-битный идентификатор
  (`random_bytes`) — без него скачать файлы нельзя.
- `storage/` закрыта от прямого HTTP-доступа (`.htaccess`); файлы
  отдаются только через `file.php`/`zip.php` с проверкой пути.
- MIME-тип определяется на сервере (`finfo`), а не по расширению или
  заголовку от клиента.
- SVG и HTML никогда не отдаются как `inline` (могут содержать скрипты) —
  только как вложение для скачивания; остальные inline-ответы отдаются
  с жёстким `Content-Security-Policy: default-src 'none'; sandbox`.
- Текстовый предпросмотр вставляется в страницу через `textContent`, а
  не `innerHTML`, поэтому содержимое файла не может быть интерпретировано
  как HTML/JS.
